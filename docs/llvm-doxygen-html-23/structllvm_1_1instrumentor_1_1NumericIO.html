Detailed Description

Instrumentation opportunity for numeric operations.

This includes Add, FAdd, Sub, FSub, Mul, FMul, UDiv, FDiv, SDiv, URem, SRem, FRem, Shl, LShr, AShr, And, Or, Xor, and FNeg.
