Detailed Description

A helper class to return the specified delimiter string after the first invocation of operator StringRef().

Used to generate a comma-separated list from a loop like so:

ListSeparator LS;
for (auto &I : C)
OS << LS << I.getName();
I
#define I(x, y, z)
