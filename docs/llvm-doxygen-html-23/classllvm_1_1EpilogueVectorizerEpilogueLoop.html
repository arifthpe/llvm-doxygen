◆ createVectorizedLoopSkeleton()

BasicBlock * EpilogueVectorizerEpilogueLoop::createVectorizedLoopSkeleton ( )
finalvirtual

Implements the interface for creating a vectorized skeleton using the epilogue loop strategy (i.e., the second pass of VPlan execution).

This function creates a new scalar preheader, using the previous one as entry block to the epilogue VPlan.

The minimum iteration check is being represented in VPlan.
